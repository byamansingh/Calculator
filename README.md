# Calculator

A desktop calculator built in Java Swing, styled after the Windows 11 calculator. Supports standard arithmetic with operation chaining, percentages, square/square root/reciprocal, full keyboard input, and clean number formatting.

## Download

The compiled `Calculator.jar` is available on the [Releases](../../releases) page.

## Running

Requires Java 17 or newer.

```bash
java -jar Calculator.jar
```

## Functions

| Function | Description |
| --- | --- |
| `+` `−` `×` `÷` | Standard arithmetic, with chaining |
| `%` | Context-aware percentage |
| `1/x` | Reciprocal |
| `x²` | Square |
| `√x` | Square root |
| `+/-` | Sign toggle |
| `C` / `CE` | Clear all / clear entry |
| `⌫` | Backspace |

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0`–`9`, `.` | Enter numbers |
| `+` `-` `*` `/` | Operators |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete last digit |
| `Delete` | Clear entry (CE) |
| `Esc` | Clear all (C) |
